# V1-M1 — Project Scope Lock

## Project
Vectis Lets Weld

## App
AI-Weld Settings Library / Vectis Weld Recipe Control

## Purpose
Create a controlled weld settings library for repeatable mild steel weld recipes on the Vectis cobot using the Miller 352 MPa.

## V1 Machine Scope
- Vectis cobot
- Miller 352 MPa

## V1 Material Scope
- Mild steel only

## V1 Allowed Processes
- MIG
- Pulse MIG

## V1 Allowed Wire
- .035 ER70S-6
- .045 ER70S-6

## V1 Allowed Gas
- Shop-used mild steel gas only

## Core Workflow
Collect → Test → Approve → Lock → Reuse

## V1 Exclusions
- No stainless
- No aluminum
- No flux-core
- No metal-core
- No automatic AI weld recommendations yet

## Production Lock Rule
No production recipe can be locked without test result approval.

## Locked Principle
Collect first. Test second. Lock third. Recommend later.
