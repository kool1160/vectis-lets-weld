# Weld Data Capture Notes

## Purpose
Capture rough weld data, operator observations, settings screenshots, and test notes before they become formal recipe records.

## Capture Guidance
For each weld trial, collect:
- Material thickness
- Joint type
- Wire diameter and type
- Gas
- Miller program
- Wire feed speed
- Trim / arc length
- SharpArc / arc control
- Travel speed
- Weave type and parameters
- CTWD / stickout
- Torch angle
- Fit-up condition
- Visual result
- Pass / fail decision

## Rule
Notes are working data only. Production recipe lock requires test result approval.
